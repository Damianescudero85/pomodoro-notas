# Pomodoro + Notas

Aplicación web de una sola página para técnica Pomodoro con lista de tareas integrada.

## Características

- Temporizador con tres modos: Enfoque (25 min), Descanso corto (5 min) y Descanso largo (15 min).
- Lista de tareas: agregar, marcar como completadas y eliminar.
- Vinculación de pomodoros a una tarea activa.
- Estadísticas de pomodoros completados hoy, en total y minutos enfocados hoy.
- Sonido al finalizar cada intervalo.
- Persistencia local mediante `localStorage` (los datos no salen del navegador).

## Uso

Abre [`index.html`](index.html) directamente en el navegador. No requiere instalación ni dependencias.

## Tecnologías

HTML, CSS y JavaScript vanilla, sin frameworks ni build step.
